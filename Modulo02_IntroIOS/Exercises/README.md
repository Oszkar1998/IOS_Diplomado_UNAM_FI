# Ejercicios — Introducción al desarrollo de apps móviles iOS

## Convención de carpetas

Cada sesión de sábado va en su propia carpeta, nombrada:

```
YYYY-MM-DD-tema-corto/
```

Ejemplo: `2026-08-29-variables-y-tipos/`

Dentro de esa carpeta va todo lo de esa clase: el/los `.swift`, el Playground, o el proyecto Xcode completo (`.xcodeproj` incluido) si el ejercicio ya requiere una app.

**Por qué por sesión y no todo suelto:** en cuanto empecemos a crear proyectos completos de Xcode, cada uno necesita su propia carpeta — no se pueden mezclar varios `.xcodeproj` en el mismo directorio.
