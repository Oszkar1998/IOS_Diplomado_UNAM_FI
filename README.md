## Estructura

```
IOS_Diplomado_UNAM_FI/
├── CALENDARIO.md                          # seguimiento de sesiones vs. módulos
├── Modulo01_Swift/
│   ├── Teoria/                            # notas de clases de viernes
│   ├── Ejercicios/                        # ejercicios de sábados (uno por sesión)
│   └── Proyecto/                          # proyecto integrador del módulo
├── Modulo02_IntroIOS/
├── Modulo03_UI_Vistas/
├── Modulo04_FlujoDeDatos/
├── Modulo05_ServiciosWebAPIS/
├── Modulo06_KitsPruebasPublicacion/
└── ProyectoFinal/
    └── Docs/
```

Cada módulo tiene la misma estructura interna:
- **`Teoria/`** — apuntes y notas de las clases de los viernes (tabla de fecha/tema/notas en el README de la carpeta)
- **`Ejercicios/`** — código de los ejercicios prácticos hechos en clase los sábados, cada uno en su propia carpeta `YYYY-MM-DD-tema/`
- **`Proyecto/`** — el proyecto integrador de ese módulo (más grande que un ejercicio suelto, normalmente un proyecto Xcode completo)
